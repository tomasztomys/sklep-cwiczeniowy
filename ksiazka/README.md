# Tekst książki

Tu leżą rozdziały i dodatki wyeksportowane z dokumentu książki jako Markdown.
Pliki są w `.gitignore`: Claude Code czyta je lokalnie, ale nie trafiają do publicznego repozytorium.

Nazwy plików:

- `00-wstep.md`
- `rozdzial-01.md` … `rozdzial-20.md`
- `dodatek-a.md` … `dodatek-f.md`

Po poprawce w dokumencie książki wyeksportuj zmieniony rozdział ponownie i nadpisz plik.
