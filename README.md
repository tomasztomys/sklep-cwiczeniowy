# Sklep ćwiczeniowy

Sklep internetowy do ćwiczeń z książki „Automatyzacja testów z agentem AI u boku.
Start z Playwright i TypeScript”. Ma stałe dane startowe, konta testowe, kody rabatowe,
tryby błędów i kilka celowych usterek dostępności do znalezienia.

> Repozytorium jest w budowie. Wersja 1.0 będzie dostępna jako obraz
> `ghcr.io/tomasztomys/sklep-cwiczeniowy:1.0`.

**Czytasz książkę?** Nie potrzebujesz tego kodu. Sklep uruchamiasz z obrazu Dockera
według rozdziału 3, a wymagania i opis API znajdziesz w `docs/specyfikacja.md`.
Swoje testy piszesz w repozytorium utworzonym z szablonu
[testy-sklepu](https://github.com/tomasztomys/testy-sklepu).

## Zawartość

- `docs/` – specyfikacja sklepu, celowe usterki, decyzje i rozbieżności z książką
- `wzorzec/` – makieta sklepu i kod z książki, na których sprawdzono przykłady
